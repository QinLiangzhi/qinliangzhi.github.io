# 在线数据库入口

> 只放「入口链接」和「一句话备注」，不放文献全文。读文献请点链接去原站读。
> ⚠️ 本站是公开 GitHub Pages，受版权保护的 PDF 全文、带水印的内部资料**不要**下载后传上来。

## 中文学术（中文友好，优先用这几个）

- 中国知网 CNKI：https://www.cnki.net  —— 中文期刊 / 学位论文主库，学校一般买过，用校园网或图书馆入口能下全文
- 万方数据：https://www.wanfangdata.com.cn  —— 中文期刊 / 会议 / 标准
- 维普：http://www.cqvip.com  —— 中文科技期刊
- 中国兽药信息网：https://www.ivdc.org.cn  —— 兽药法规、批准文号查询（专业用）

## 英文 / 国际（英文吃力时配合浏览器右键「翻译成中文」）

- PubMed：https://pubmed.ncbi.nlm.nih.gov  —— 生物医学文献，免费摘要
- PubMed Central (PMC)：https://www.ncbi.nlm.nih.gov/pmc  —— **开放获取全文库**，找不到全文时先来这搜
- Google 学术：https://scholar.google.com  —— 跨库检索，常能链到开放全文
- Semantic Scholar：https://www.semanticscholar.org  —— AI 辅助检索，有中文界面选项
- ScienceDirect：https://www.sciencedirect.com  —— 外文期刊（多数需机构订阅）

## 中兽医 / 兽医专用资源

- 中兽医相关论文：在 CNKI / 万方 用「中兽医」「中兽医学」检索即可
- 古籍《元亨疗马集》等：国家图书馆 / 中医古籍数据库（如中国中医科学院中医药信息研究所资源）
- 开放教材：部分高校把《中兽医学》课件放到校内开放平台，检索「中兽医学 开放课件」

## 怎么用

1. 点链接去对应库检索你要的主题。
2. 觉得有用的文献，到「我的书单」或对应笔记里记「标题 + 出处 + 我的批注」。
3. 找不到全文 → 先试 PMC / Semantic Scholar / Google 学术的「PDF」链接。
4. 英文页面看不懂 → 浏览器空白处点右键 → 「翻译成中文（简体）」。
