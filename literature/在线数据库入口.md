# 在线数据库入口

中文库：中国知网 CNKI（https://www.cnki.net）、万方（https://www.wanfangdata.com.cn）、维普（http://www.cqvip.com）、中国兽药信息网（https://www.ivdc.org.cn）。

英文 / 国际：PubMed（https://pubmed.ncbi.nlm.nih.gov）、PubMed Central 开放全文（https://www.ncbi.nlm.nih.gov/pmc）、Google 学术（https://scholar.google.com）、Semantic Scholar（https://www.semanticscholar.org）、ScienceDirect（https://www.sciencedirect.com）。

中兽医 / 兽医专用：CNKI / 万方 检索「中兽医」「中兽医学」；古籍《元亨疗马集》等见国家图书馆 / 中医古籍数据库；部分高校开放《中兽医学》课件可检索「中兽医学 开放课件」。

注意：本站为公开站点，受版权保护的 PDF 全文、带水印内部资料不要上传。
