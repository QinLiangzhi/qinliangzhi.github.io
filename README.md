# 中兽医学习笔记

> 我的中兽医 / 宠物医疗学习沉淀站 · 用 Docsify + GitHub Pages 零代码搭建

这里是我的个人学习笔记站。边学边记，慢慢沉淀。

## 怎么用这个站

- 左边是目录（侧边栏），点开就能看对应的笔记。
- 想加新笔记：在 `notes/` 文件夹里新建一个 `.md` 文件，然后在 `_sidebar.md` 里加一行链接即可。
- 支持搜索：右上角放大镜，输入关键词就能在全站笔记里找。
