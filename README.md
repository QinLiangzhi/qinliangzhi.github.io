# 中兽医 · 专业文献与笔记中枢

这个站是我的**个人学习中枢**：读文献在别处（知网 / 万方 / PubMed 等），把读到的东西变成结构化的索引和笔记，放在这里。

## 站点的三块

- **文献索引** —— 数据库入口、我的书单、按主题归类的文献索引（只存链接与批注，不存受版权保护的原文）。
- **笔记区** —— 按主题记我的学习笔记（中兽医基础 / 临床诊疗 / 实习见闻）。
- **心得与复盘** —— 周复盘、疑问收集，帮我把零散的学习串起来。

## 怎么用

- 左侧目录点开即看；右上角放大镜可全站搜索。
- 想加内容：在对应文件夹新建 `.md` 文件，再到 `_sidebar.md` 加一行链接即可。
- 本仓库**完全公开**，任何人都能访问。请不要写入受版权保护的文献全文，也不要写很私人的内容。

## 关于
